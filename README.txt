DATE ROMANTIQUE ❤️

1. Ouvre index.html dans un navigateur.
2. Le site utilise EmailJS via son CDN.
3. La configuration EmailJS est déjà renseignée dans script.js.
4. Le template EmailJS doit utiliser exactement :
   {{date}}
   {{time}}
   {{message}}

Si EmailJS renvoie encore une erreur 400 :
- regarde la fenêtre d'erreur affichée par le site ;
- copie le texte après "Message :".
Ce texte permettra d'identifier précisément le problème de configuration EmailJS.
